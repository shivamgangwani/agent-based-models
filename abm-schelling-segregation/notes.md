# Notes on Schelling's Segregation Model

The similarity index is the quantitative measure of interest. At initialisation, if the agents have been assigned truly randomly across the grid, then the similarity index is approximately the proportion of type A agents. Even with mildly "racist"/ingroup preferences (a 30% threshold), we see the similarity index jump up to 75%. 

The main result is that, even though agents themselves do not exhibit any extreme preferences, the resulting outcome does show significant segregation. 


Some interesting questions that are worth exploring:
1. What happens as we make the grid a bit irregular? Circular, triangular, hmmm, perhaps add some natural barriers (rivers, mountains, etc)?
2. What if there are more than just 2 types of agents?
3. What if preferences are not identical, e.g. only red agents have ingroup preferences and the blue ones are indifferent?
4. There are extensions of this simple model. Maybe it's worth implementing some of those?
